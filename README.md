## 📋 About The Project

Bimal Pathology & Diagnostic Center is a state-of-the-art laboratory located in **Bharatpur, Chitwan, Nepal**.  
This website serves as the digital front door for patients, providing:

- Information about cutting-edge diagnostic machines.
- A complete list of available tests and panels.
- Lab timings, location, and emergency contact details.
- Trust signals (99.2% accuracy, NABL accreditation, digital reporting).

The website is fully **responsive**, **mobile-first**, and optimized for fast loading.
